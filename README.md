# Домашнее задание к работе 9

## Условие задачи
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа, условие заполнения фигуры и задаваемые параметры фигуры в таблице

## 1. Алгоритм и блок-схема

### Алгоритм
  **Начало**
   - `s1` - сторона 1 квадрата
   - `s3` - сторона 2 квадрата
   - `s2` - область пересечения квадратов
   - `c` - символ заполнения квадратов
   - `size` - равный сумме двух кдваратов и разности их перечения
   - Проверить условие i < size и выполнить действие i + 1
   - Проверить условие j < size и выполнить действие j + 1
   - `a1` - i < s1 && j < s1
   - `a2` - i >= s1 - s2 && i < s1 - s2 + s3 && j >= s1 - s2 && j < s1 - s2 + s3
   - Если a1 && a2 вывести на экран пробел
   - Иначе если a1 || a2 вывести на экран символ c
   - Иначе вывести пробелы
   - Вывести результат программы
  **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <locale.h>
#include <stdio.h>

int main()
{
	setlocale(LC_CTYPE, ".UTF-8");

	int s1, s2, s3;
	char c;

	printf("Введите сторону s1 первого квадрата\n");
	scanf("%d", &s1);

	printf("Введите сторону s2 области пересечения двух квадратов\n");
	scanf("%d", &s2);

	printf("Введите сторону s3 второго квадрата\n");
	scanf("%d", &s3);

	printf("Введите символ\n");
	scanf(" %c", &c);

	if (s1 <= 0 || s2 <= 0 || s3 <= 0 || s2 > s1 || s2 > s3)
	{
		printf("Размеры заданы неверно");
		return 1;
	}
	int size = s1 + s3 - s2;
	for (int i = 0; i < size; i++)
	{
		for (int j = 0; j < size; j++)
		{
			int a1 = (i < s1 && j < s1);
			int a2 = (i >= s1 - s2 && i < s1 - s2 + s3 && j >= s1 - s2 && j < s1 - s2 + s3);

			if (a1 && a2)
				printf(" ");
			else if (a1 || a2)
				printf("%c", c);
			else
				printf(" ");
		}
		printf("\n");
	}
	return 0;
}
```
